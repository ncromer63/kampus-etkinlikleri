# Kampüs Etkinlikleri

Bu depo, Üniversite Kampüs Etkinlikleri uygulamasının Sprint 1–4 adımlarını içerir.

## Canlı Yayın Adresi
- **Vercel Canlı Link:** https://kampus-etkinlikleri-seven.vercel.app/

Sprint 4 sonrası Vercel ayarı: **Root Directory** `frontend`, **Framework Preset** Vite.

## Sprint 4 dosyaları
- `frontend/package.json` — proje adı, `dev`/`build` komutları ve paket listesi
- `frontend/package-lock.json` — yüklenen paketlerin tam sürümleri
- `frontend/node_modules/` — indirilen paketler; GitHub’a gitmez
- `frontend/tsconfig*.json` — TypeScript ayarları
- `frontend/vite.config.ts` — Vite ayarları ve React eklentisi
- `frontend/index.html` — tek HTML; içinde boş `div#root`
- `frontend/src/main.tsx` — React’i başlatır, App’i root’a çizer
- `frontend/src/App.tsx` — uygulamanın ana bileşeni (5 sayfa, state ile geçiş)
- `frontend/src/App.css` — Sprint 3 CSS’i (öğrenci no 2416501085)
- `frontend/src/index.css` — genel stil; bu sprintte boş
- `frontend/public/` — olduğu gibi kopyalanan dosyalar (afiş)

## Sprintler
1. **Sprint 1 (HTML, Git ve Yayına Alma):** Semantik HTML iskeleti, 5 sayfa, erişilebilir formlar (sprint-01).
2. **Sprint 2 (CSS ve Responsive Tasarım):** Numaraya göre CSS değişkenleri (--ton: 5, --font: "Times New Roman"), grid kart düzeni, responsive tasarım (sprint-02).
3. **Sprint 3 (JavaScript ve DOM):** Modüler ES yapısı, arama + kategori filtreleme, URLSearchParams ile detay (sprint-03).
4. **Sprint 4 (Vite, TypeScript ve React):** `frontend/` içinde React-TS; tipli veri, saf fonksiyonlar, 5 sayfa tek `App.tsx` içinde, `useState` + `useEffect` (sprint-04).
